# Documentation

Start with the [README](../README.md) for the one-minute overview. Then pick the shelf for what you need to do.

## Product: what it is and whether it fits

- [PRODUCT.md](PRODUCT.md): the one-page brief. Who it is for, jobs to be done, rollout, what it is not, FAQ.
- [EVIDENCE.md](EVIDENCE.md): every headline number with its source and caveats.
- [APP.md](APP.md#swarm-theater): the Swarm Theater, a 90-second replay of a 1,000-agent run.
- [../RELEASE.md](../RELEASE.md): v1.0 release notes and known limits.
- [../policies/README.md](../policies/README.md): the four policy packs and their limits.

## Integrators: install, connect, operate

- [QUICKSTART.md](QUICKSTART.md): from clone to a refused order in Python, HTTP, Node or MCP, offline.
- [GUIDE.md](GUIDE.md): user guide. Concepts, install, first run, the dashboard, integrating your agent, troubleshooting, FAQ.
- [API.md](API.md): HTTP endpoints, auth, limits ([openapi.json](openapi.json)).
- [MCP.md](MCP.md): OrderGuard as an MCP server for any MCP client.
- [OPERATIONS.md](OPERATIONS.md): configure, Docker, receiver bridge, budgets, record and replay, backup, upgrade.

- Examples that refuse an order, one per language: `../examples/python/guarded_agent.py`, `../examples/http/check_order.sh`, `../examples/node/check-order.mjs`, `../examples/mcp/` (see [QUICKSTART.md](QUICKSTART.md)).
- Packages: `../packages/sdk/README.md` (Node SDK for the receiver), `../packages/mcp-server/README.md` (MCP over the receiver), `../examples/quickstart/README.md` (offline receiver quickstart).

- [ARCHITECTURE.md](ARCHITECTURE.md): the eight layers, the data flow, what each guarantees and does not.
- [THREAT-MODEL.md](THREAT-MODEL.md): what an attacker can do, which layer stops it, what is not defended.
