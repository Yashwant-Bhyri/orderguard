What it does

Three things your agents can't do without you

Rules

Set the rules once. Enforce them on every order

You sign a mandate for a whole strategy: which symbols, how large an order can be, how much a day, and above what size a person must approve. The agent never holds the signing key, so it can't widen its own limits. Every order is sized at OrderGuard's trusted market price, not the price the agent says it saw.

    Risk

    Catch the risks that individual limits miss

    An order can pass every limit and still be dangerous: one of five agents quietly building the same position, a trade on a headline nobody else has reported, a command hidden in a web page. Every order goes through the same five stops, and the risk model watches the whole swarm. It can hold an order for a person. It can never approve one the mandate refuses.

      Record

      Know why every order was allowed, held or refused

      Each decision is written with the mandate, the trusted price and the reason, and sealed into the record before it, so the history can't be quietly changed. Held orders wait in a review queue ranked by the money at stake, so a person sees the riskiest order first.
