    Only code says yes

    Models read text and rank the review queue. Whether an order reaches the ledger is decided by a signed mandate, a trusted price and plain code, in that order.

    1. The owner signs a mandate

      Symbols, sides, per-order and daily caps, a price band and a "get a human above this size" threshold, signed with the owner's key. Any edit after signing breaks the signature.

    2. Prices come from venues, not agents

      Every order is sized at a trusted market price, never at the price the agent claims. That is what caught the forged split.

    3. The mandate check decides

      Allow, hold or refuse, each with reasons in plain words. Optional portfolio caps per symbol, position and day stop many agents from splitting one big position.

    4. The risk layer can only tighten

      A behavioural model watches the whole swarm for splitting, bursts and runaway loops. It can turn an allow into a hold or a refusal, never the other way.

    5. People review what matters first

      Held orders queue by expected bad dollars. Model advice can add a hold or a warning; there is no code path from advice to an approval.

    6. The receiver writes the ledger

      The final authority re-checks the signed mandate at commit time, with idempotency, revocation and a hash-chained paper ledger.

    Before any of this, what agents read is screened. Hidden characters and look-alike tickers are exposed in code (L1), manipulative text is caught and its repeats quarantined (L2, L3), cited figures are checked against SEC filings (L6), and a "sell if it crashes" rule fires only when two independent sources agree (L7).
