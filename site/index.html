        The signed mandate

        You sign what your agents may do, once. They work inside it, and never hold the key.

        1. You describe the taskin plain words
        2. OrderGuard drafts the mandatenames, sides, limits
        3. The adapter checks it fitsno more than the task needs
        4. You sign it, oncewith your own key

        Trusted data

        Agents that run for weeks fill their memory with their own summaries. Some drift, some have no source. Before an order relies on any of it, every price and figure is traced to a source the agent can't touch.

        In the recorded run, all orders placed on one-source news, in all, waited for a second source.

        Introducing the swarm risk model

        Limits see one order at a time. Harm in a swarm is spread across many. So we built our own model, self-trained on labelled orders, that sees the whole swarm.

        1. Every order the mandate allowsbefore it reaches the broker
        2. behavioural signalseach measured against the run so far: the mandate, the agent's own rhythm, the other agents, the market. Never the agent's words
        3. detectors and treesdetectors written from the mandate and known failure patterns set a floor; the trees, trained on recorded swarm runs, add the rest
        4. Hold or refuseit can make a decision stricter, never approve one

        And a decision adapter

        Limits say how much. The adapter asks what for. It checks that what an agent asks for serves what it was asked to do, and, while it runs, that each order is what it said it was doing.

        1. Code goes firsta draft that doesn't fit inside your signed mandate never reaches the model
        2. Natively calibrated parametersthe decision model returns probabilities it means, not prose: does it serve the purpose, does it ask for more than it needs, and which concern applies
        3. A calibrated scopeone score against a flag line; above it, a person looks before anyone signs

        Supervision

        When agents crowd into the same trade, their buying moves the price, and the rising price looks like proof. OrderGuard slows the crowd before it feeds on itself.

        The final check

        Agents trade in waves. Right before each order reaches your broker, it is checked one last time, inside the mandate, against every fact it relies on, as they stand now.

        In the million-agent simulation, orders went through this check. broke a limit.

        The review queue

        Held orders wait for a person, most money at stake first, so their time goes where the risk is.
